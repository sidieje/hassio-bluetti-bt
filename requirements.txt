# Pinned to the Home Assistant release this integration is developed and tested
# against. An unpinned homeassistant lets CI install a newer core than anyone
# runs locally, which changes behaviour under test. Bump deliberately, and
# re-check the aiousbwatcher/pyserial pins against the new release's
# homeassistant/package_constraints.txt and component manifests.
homeassistant==2026.2.3
# Pinned to a library release tag, not to the ha-deployment branch, and to the
# same release as the requirement in
# custom_components/bluetti_bt/manifest.json. The branch moves independently of
# this repo, so a branch pin lets one integration version build against
# different library code on different days: CI can go red with no change here,
# and a fresh install can pick up code nobody has tested. Bump both pins
# together when the library releases.
bluetti-bt-lib @ git+https://github.com/sidieje/bluetti-bt-lib.git@v1.0.13
